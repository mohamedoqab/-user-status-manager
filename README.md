# User Status Manager

A simple web application for managing users and their status.

## About the Project

This project was developed as part of my Web Development training.  
It allows users to be added and managed through a simple and user-friendly interface.

## Features

- Add new users
- Display users
- Manage user status (Active / Inactive)
- Store user information in a MySQL database
- Simple and responsive interface

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Database

The `database.sql` file contains the SQL structure required to create the users table.

## Project Files

- `index.php` — Main application file
- `database.sql` — Database structure
